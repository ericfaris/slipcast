Signal Deck

Slipcast's design system — a broadcast-control-room identity for a self-hosted YouTube→podcast relay. Every token and component below is rendered live from this app's own /static/styles.css, not redrawn. See DESIGN.md in the repo root for the full narrative.

v1.0 · Signal Deck

Color

Surfaces and ink flip automatically with the OS color scheme (prefers-color-scheme) — toggle your system theme to see every swatch below repaint. Brand-a/brand-b are the fixed red→violet signal gradient used in the logomark and primary buttons; they intentionally do not shift between themes.

Backgrounds & texture

Pure-CSS textures (no image weight) that carry the "broadcast console" feel: an oscilloscope dot-grid behind the whole app, a signal-glow wash used on this page's hero, and a scanline pattern reserved for future technical panels.
